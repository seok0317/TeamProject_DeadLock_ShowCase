# Deadlock 모작 — Showcase

팀 프로젝트에서 `seok0317`이 담당한 구현과 공통 시스템에 추가한 기능을 정리한 게임 클라이언트 개발 포트폴리오입니다.

## 프로젝트 소개

캐릭터 고유 스킬과 다양한 이동 액션으로 전장을 공략하고, 미니언·포탑 전투와 성장을 거쳐 상대 넥서스를 파괴하는 팀 기반 3인칭 슈팅 프로젝트입니다.

## 담당 영역

**플레이어 조작 및 이동**

- 카메라 기준 조작, 공중 대시, 구르기와 연계 점프, 이단 점프
- 벽 감지·매달림·벽 점프, 경사 슬라이딩, 커브 기반 자동 파쿠르
- 커스텀 이동 예측 데이터와 이동기 상태 연계

**Lash 캐릭터 및 스킬**

- 지상·공중 강하 공격, 그래플 도약, 다중 대상 공격과 흡혈
- 응시 락온, 적 끌어올리기·투하, 착지 좌표 RPC 전달
- 다중 대상 GameplayCue 연결과 로프·범위 이펙트 연계

**게임 HUD 및 인벤토리 UI**

- 체력·활력·탄약·재장전·레벨·소울·스킬 상태 표시와 강화 메뉴
- 월드 체력바, 피아·거리·가림 판정, 복제 준비 지연에 대한 초기화 처리
- 인벤토리 HUD 슬롯 재사용·정렬, 아이템 쿨타임, Pawn/인벤토리 이벤트 연계

**넥서스 및 게임 종료 흐름**

- 체력 기준 2단계 전환, 광역 공격과 연출 동기화
- 최종 포탑 파괴에 따른 무적 해제, 넥서스 아군 피해·무적 방어
- 넥서스 파괴 이벤트와 결과 UI·로비 복귀 연결
